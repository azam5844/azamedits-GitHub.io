# MyServer — Local Web Server Landing Page

This repository contains a simple HTML landing page for **MyServer**, describing a local web server and how to test a website on localhost.

## What the page shows

- A MyServer heading and short introduction
- A notice that the local web server is running
- A reminder to test a website locally and place site files in the document root

## Files

- `index.html` — page content and embedded styles.

## Preview

Open `index.html` in a browser, or serve the folder using your preferred local development server.

## Note

The current page is an informational landing page; it does not itself install or configure a web server.
